# i18n Rules (`apps/front-end/`)

Internationalization uses [`i18next`](https://www.i18next.com/) + [`react-i18next`](https://react.i18next.com/). Config lives in `src/lib/i18n.ts`; it is imported once for its side effect in `src/main.tsx` (`import "@/lib/i18n";`) before the app renders.

## Translation files

- Messages live in `src/translations/<locale>.json` — one file per locale.
- Supported locales: **`en`** (default + fallback) and **`rs`** (Serbian). Listed in `SUPPORTED_LOCALES`.
- **`en.json` is the source of truth** for the key set — its shape types `t()` via `src/types/i18next.d.ts` (which augments `i18next`'s `CustomTypeOptions`, deriving `resources`/`defaultNS` from `@/lib/i18n`). Add a key to `en.json` first, then mirror it in every other locale. A missing key falls back to `en`.
- Keys are nested by area (`install.steps.init`). Use interpolation for dynamic values: `"portalLanguage": "Portal language: {{lang}}"` → `t("home.connection.portalLanguage", { lang })`. Interpolation does not HTML-escape (`escapeValue: false`) — React already escapes.

## Using translations

- In components: `const { t } = useTranslation();` then `t("install.title")`. Keys are type-checked — a typo or missing key is a compile error.
- Never hardcode user-facing strings in JSX. (The `home` page is intentionally left untranslated as a minimal example — don't copy that.)
- Outside React (plain modules), import the default `i18n` instance and call `i18n.t(...)`.

## Locale detection (Bitrix24)

- The portal language comes from `$b24.getLang()`, surfaced via `useB24Init`'s `onLocaleDetected(lang)` callback.
- `setAppLanguage(lang)` from `@/lib/i18n` maps a B24 lang code → a supported locale (via `B24_LANG_MAP`, defaulting to `en`) and calls `i18n.changeLanguage`. Wire B24 lang codes to locales there, not at call sites.
- The install page (`features/install/`) calls `setAppLanguage($b24.getLang())` right after `initializeB24Frame()` so install UI matches the portal language.

## Adding a locale

1. Add `src/translations/<locale>.json` (copy `en.json`, translate values).
2. Register it in `src/lib/i18n.ts`: add to `SUPPORTED_LOCALES`, `resources`, and any relevant `B24_LANG_MAP` entries.
